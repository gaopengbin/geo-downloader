# GeoDownloader v3.6.26

本次更新完善下载调度、OSM 服务容错和下载中心的操作体验。

## 下载调度可配置

- 在“设置 → 默认下载参数 → 下载调度”开放每秒请求上限、每批请求数和批次停顿时间。默认保留自动策略，可配置固定停顿或随机停顿。
- 相同服务与 Token 的任务共享预算，整批请求完成后才开始停顿；保存后用于后续请求，服务端要求的冷却时间仍保留。
- 天地图请求更平稳，遇到偶发限流时更快恢复已验证的速度，反复限流时自动降低速度；限流不会误判为 Token 额度耗尽。
- 调度设置适用于常规瓦片下载；地图浏览、Google Earth 历史影像、OSM 查询和 3D 下载保持独立调度。

## 图层选择联动

- 左侧下载参数与右侧地图图层共用叠加层选择和顺序，开关操作同步影响地图预览及新建下载任务。
- 保留自定义栅格图源配置，过滤已移除、重复或不支持叠加的图层。

## OSM 下载容错

- Overpass 服务连接失败、超时或异常时，按顺序尝试备用服务，并显示切换状态；限流时等待后继续尝试。
- 查询被拒绝或服务返回不完整结果时明确报错，不将半截数据导出为成功结果；失败任务及记录保留。

## 下载中心更清晰

- 调整任务、可恢复任务及历史卡片，长标题和图源省略展示，自动名称去除重复信息；下载日期并入统计行。
- 文件操作移到底部，统一为图标加短标签；完整路径仍可查看和复制，失败任务不显示误导性的文件夹入口。
- 侧栏最小宽度为 380px，避免卡片挤压；复选框更清楚，所有底部操作采用一致尺寸和间距。
- 下载中心及任务弹窗采用统一的自定义 Tooltip，支持深浅主题、长内容换行、窗口边缘避让与键盘操作。

服务侧的访问限制、配额或网络异常仍可能影响下载；本次更新提供自动恢复和清晰的失败反馈。
