# v3.6.8 - 区域边界导入与下载范围书签

本次版本集中修复真实用户文件中的区域几何兼容问题，并新增可重复使用的下载范围书签。

## 区域边界导入

- 支持将 KML/KMZ 中首尾闭合的 `LineString` 边界识别为 `Polygon` 下载区域。
- 支持递归提取混合 `GeometryCollection` 中的面要素；同一集合同时包含面、开放线或点时，不再漏掉有效区域。
- 标准 `Polygon` / `MultiPolygon` 保持原有语义，开放线和点不会被错误转换为面。
- 区域选择和批量下载共用同一套面几何提取规则，bbox、裁剪边界和要素列表保持一致。
- 文件只包含开放线或点时，提示会明确说明无法作为下载区域，并引导转换为 `Polygon`。
- 新手引导和上传入口补全 GeoJSON、Shapefile、KML、KMZ 格式说明。

## 下载范围书签

- 可将当前行政区、手绘矩形/多边形或导入边界保存为命名书签。
- 支持一键恢复选区并同步更新地图，也可在书签管理中重命名或删除。
- 书签只记录下载范围，不绑定图源、缩放级别、输出格式等任务参数。
- 书签保存在本机应用数据目录的独立 SQLite 数据库中，大型 KML 边界不会占用 WebView 本地缓存额度。

## 新手引导 v2

- 主界面总览更新为 GeoD 当前的六种数据模式和统一下载中心流程。
- 新增“区域选择与地图工具”“下载中心”专项引导，覆盖范围书签、量测、经纬网、任务批量操作与历史记录。
- 新增 MVT 和 OSM 独立下载引导，并更新影像、3D Tiles、Wayback 引导入口。
- 从任意页面启动专项引导时，会先自动切换到正确模式和侧栏页面，避免引导指向隐藏内容。
- 已看过旧版主引导的用户升级后会看到一次 v2 总览，之后不会重复打扰。

## 匿名使用统计

- 增加下载任务、范围选择、边界导入、范围书签、地图量测和新手引导的匿名功能事件，后台可按固定分类查看功能采用情况。
- 要素数、坐标点数和缩放级别数只按区间统计，不上传文件名、路径、URL、地图坐标、图源密钥、错误原文或用户数据。
- 收集服务对事件字段和值执行严格白名单校验，夹带额外字段的事件会被拒绝，不会写入数据库。
- 匿名统计说明升级至 v2，旧版已同意用户会重新确认一次；拒绝或关闭不会影响下载、预览、导出及更新。

## 验证

- 使用用户反馈 KML 验证两条闭合边界能够整理为包含 2 个面的 `MultiPolygon`，完整保留 4313 和 8862 个坐标点。
- 新增闭合线、多面、嵌套/混合集合、开放线、点和标准面回归测试。
- 新增范围书签保存、重命名、删除及 15000 点大型边界持久化测试。
- 验证新版帮助菜单、下载中心自动切页，以及区域工具全部 6 个引导目标。
- 本次升级不会删除已有任务、历史记录、输出文件或瓦片缓存。
