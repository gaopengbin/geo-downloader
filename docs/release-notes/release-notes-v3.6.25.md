# GeoDownloader v3.6.25

## 下载可靠性与结果定位

- 修复 OSM 请求或写文件失败后任务直接消失的问题：失败任务保留原因，OSM 成功和失败均写入历史记录。
- 下载结果展示完整保存路径，提供“打开文件夹”和“复制路径”。OSM 文件缺失或被移动时明确提示。
- OSM 文件先写入同目录临时文件，完成写入、刷新和校验后再替换目标；失败或提交前取消时保留原文件。
- 高德与天地图下载使用各自共享的请求节奏，在任务、子域和叠加层之间协调并发；遇到 429/503 按服务响应等待并有界重试。
- 天地图 429 不再错误切换或消耗备用 Key；401/403 继续尝试用户配置的备用 Key。持续失败保留任务数据，并显示明确原因，不将 HTTP 状态直接判断为日额度耗尽。

## 自定义叠加图层

- 地图“图层 → 配置叠加图层”可选择任意已配置栅格图源，并搜索、新增、编辑、移除与调整叠加顺序。
- 延用自定义图源的 URL、XYZ/TMS、子域、缩放级别和请求头；配置按模块记忆，平移缩放自动加载。
- 下载“输出参数”也可选择自定义叠加图层，按列表从底层到顶层合成；地图预览与下载输出分别配置。

## 在线更新

- 下载源持续低速、超时或失败时自动尝试官方备用源，显示下载速度与切源状态。
- 安装包通过大小及 SHA-256 校验后才进入安装流程，修复更新清单指向临时发布地址的问题。

## 匿名诊断

- 补充叠加层配置操作、结果定位操作与在线更新阶段的分类统计，改进 OSM 写盘失败和 GeoJSON 输出的分类。
- 沿用现有匿名统计开关；不上传图源名称、URL、请求头、Token、保存路径、坐标或原始报错。

已有设置与历史记录兼容升级。客户端重试不能改变图源服务的授权、配额或持续拒绝状态。
