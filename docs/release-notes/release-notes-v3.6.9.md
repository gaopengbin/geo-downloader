# v3.6.9 - 图源兼容、英文界面与导入效率改进

本次版本集中完善图源模板兼容、GIS 输出配套文件和多要素导入体验，同时补齐英文界面与天地图 Token 错误提示。

## 图源兼容与天地图提示

- 自定义栅格图源新增 TMS 反向 Y 占位符 `{-y}`，无需再由用户手动换算 Y 坐标。
- 新增 Bing QuadKey 占位符 `{q}`，地图预览、缓存和下载使用统一的 URL 解析规则。
- 设置页明确说明 GeoD 内置天地图 Key 为公开共享 Key，额度和可用性不受保证，并提供官方 Token 申请入口。
- 切换到天地图图源时会立即探测 Token 状态；遇到无效、无权限、缺失或额度不足时直接在界面提示，不再等全部瓦片失败。
- 下载阶段保留首个明确错误，整批失败时会显示实际 Token 或限流原因，而不是笼统提示无数据。

## GeoTIFF 输出

- GeoTIFF 与 DEM 输出可选生成 `.tfw` 和 `.prj` 辅助文件，改善部分传统 GIS 软件的坐标识别兼容性。
- 普通影像按 Web Mercator 生成辅助文件，DEM 按 WGS 84 输出对应空间参考。
- 批量下载、Wayback 和部分任务导出使用相同的辅助文件设置。

## 多要素导入

- 导入包含大量面要素的文件时，支持先点击一个要素，再按住 `Shift` 点击另一个要素进行连续选择。
- 连续选择支持正向和反向操作，也可以整段取消；点击整行或复选框行为一致。
- 全选、清空和反选后会重置连选起点，避免从旧位置意外扩展选择。
- 修复 WebView 在按下 `Shift` 时显示残留焦点描边的问题，同时保留正常键盘操作能力。

## 界面与文案

- 新增简体中文与英文界面切换，语言选择保存在本机。
- 下载、Wayback、任务中心、设置、图源管理、新手引导和常用弹窗完成统一翻译。
- 任务状态文案改为集中映射，未知状态仍会保留原始值，便于后续版本兼容。

## 安装与升级

- 本次升级不会删除已有任务、历史记录、输出文件、下载范围书签或瓦片缓存。
- Windows、Linux、macOS Intel 和 Apple Silicon 安装包继续由 GitHub Actions 构建。
- macOS 安装包尚未进行 Apple Developer ID 签名与公证，部分系统仍可能显示安全提示。
