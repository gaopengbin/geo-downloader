# v3.6.6-beta.2 - 大任务稳定性与 GeoD 助手测试版

这是一个预发布测试版本，重点验证大规模下载任务的断点恢复、磁盘空间保护，以及开发者模式下的 GeoD AI 助手。

## 关键改进

- **大任务恢复更可靠**：中间文件改为按列分目录保存，避免单个目录包含海量文件导致扫描和重启恢复变慢。
- **工作目录跟随输出盘**：新任务的临时数据保存在输出目录旁的 `.geod-work` 中，减少系统盘被大型任务占满的风险。
- **磁盘空间保护**：创建任务和下载过程中都会检查剩余空间，空间不足时保留恢复数据并给出明确提示。
- **图层面板交互修复**：图层管理改为点击展开、点击外部关闭，并修复 Wayback 时间轴与图层面板遮挡。
- **GeoD AI 助手**：作为开发者功能默认关闭，支持用户配置自己的 DeepSeek Key，通过知识库回答使用问题并跳转到相关设置。
- **智能图源配置**：可从用户提供的 URL 辅助识别瓦片模板、测试可用性并引导完成配置。

## 兼容与安全

- 旧版本保存的未完成任务仍可识别；旧的平铺式中间文件也可以继续恢复。
- AI 助手启用前会展示风险提示、免责声明和隐私说明，并要求二次确认。
- DeepSeek Key 保存在操作系统凭据存储中，不写入普通设置文件；请求可通过用户指定的 AI 网关转发。
- macOS 安装包增加 ad-hoc 签名，并由 GitHub Actions 挂载生成的 DMG 后验证其中的应用签名。

## 测试重点

- 使用数万到数十万瓦片的任务，确认下载期间界面和任务列表保持流畅。
- 中断任务并重启应用，确认任务仍在可恢复列表中，已下载瓦片无需重复获取。
- 将输出目录放在非系统盘，确认 `.geod-work` 也创建在该盘，任务完成后能够自动清理。
- 在磁盘空间不足时，确认任务停止并保留恢复数据，而不是持续写满磁盘。
- 在 GeoTIFF 与 Wayback 页面反复打开图层面板，确认面板常驻、外部点击关闭且不遮挡时间轴。
- macOS 用户请重点验证 DMG 能否正常打开及首次启动。

测试过程中如遇异常，请保留任务信息、相关日志以及 `.geod-work` 目录，以便继续定位。
