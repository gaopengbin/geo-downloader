# 国基参考要素与奥维 URL 转换

状态：本地开发完成，未发布。现有 v3.6.28 标签、安装包和线上服务均未改动。

后续调整（2026-11-07）：四类参考要素已从下载参数和原底图列表移到独立地图面板，并修复重复重建和文字绘制的卡顿。以下为初版历史记录，当前行为见 `2026-11-07-reference-map-panel-performance.md`。

## 使用入口

- 图源管理 → 自定义图源 → 奥维 URL：填写完整在线 URL，或填写服务器地址及路径模板；转换后核对名称、坐标方案、级别、子域和请求头，再保存为普通自定义图源。
- 资源下载 → 输出参数 → 叠加图层：新增“基础地理参考要素”，水系、公路、铁路和居民点 / 地名均可独立启用、设置颜色、粗细和名称；支持全局字号与坐标对齐。
- 地图右侧图层控件提供同一组参考要素开关。左右两处共用状态，设置在本机保存。
- “另存视口矢量”将当前视口内相交的完整要素分页保存为一个 WGS84 GeoJSON，附带图层类别和来源信息；完成后可打开文件夹或复制路径。

参考要素不参加当前的栅格影像合成；原有栅格叠加和下载保持原来的共同选择逻辑。

## 数据和实现

原生模块固定访问 `https://gisserver.tianditu.gov.cn/TDTService/wfs`，使用 WFS 2.0 GetFeature、CRS84 经度在前的 BBOX、EPSG:4326 输出、count / startIndex 分页。

| 参考层 | 类型 |
| --- | --- |
| 水系 | TDTService:HYDL |
| 公路 | TDTService:LRDL |
| 铁路 | TDTService:LRRL |
| 居民点 / 地名 | TDTService:AGNP |

RESP 不是具名居民点层，因此使用实测含名称的 AGNP。数据定位为参考框架，不承诺实时详细路网。此次小范围实测无须 Key；这不代表服务永久免鉴权或无限额。

地图从 8 级开始按视口自动加载，350ms 防抖；移动开始即取消旧请求并暂停导出入口，新响应通过请求 ID 校验后才应用。控制器不调用 fitBounds / setView。每层最多预览 2,000 个要素并明确提示部分预览，另存不使用这个预览上限。

请求共用 2 个网络槽位，缓存 1 天、预算 256MiB；只管理专属缓存目录内符合命名规则的文件。刷新可跳过缓存。429 / 503 按 Retry-After 有界等待一次，失败保留错误。地图使用 Canvas 绘制几何，名称以纯文本绘制，四层共用碰撞格避让，最多 250 个名称。

自动坐标对齐识别高德底图；自定义底图可手动选择。对齐只改变预览坐标，GeoJSON 保留 WGS84。跨日期变更线、无效或重复世界范围不会被静默当成可导出的普通视口。

另存逐页流式写入同目录唯一 `.part` 文件，检查剩余空间和重复 / 不完整分页；同步落盘后才原子替换目标。取消或失败清理本次临时文件、保留原目标文件。原生导出具有进度事件和取消命令。

## 奥维转换边界

支持普通 HTTP / HTTPS 在线模板、服务器加路径，以及 `{$x}` / `{$y}` / `{$z}` / `{$q}` / `{$s}` / `{$-y}` 和相应 URL 编码形式。转换不会重排或重编码鉴权查询参数。转换结果沿用现有 GeoD 自定义图源的预览、下载和请求头链路。

未实现 `.ovmap` 文件 / 二维码解析；不猜测奥维函数或动态时间变量，不将经纬度切片静默转换成墨卡托切片。此次没有奥维本地服务样本，因此验证了模板转换、图源保存及既有瓦片变量的测试，没有声称完成某个真实奥维服务的取片验收。
