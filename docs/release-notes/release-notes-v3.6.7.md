# v3.6.7 - 下载任务、Wayback 与 3D Tiles 稳定性修复

本次版本集中处理近期反馈的下载任务暂停、Wayback 扫描和 3D Tiles 下载问题，不新增大型功能。

## 下载任务

- 修复同时运行多个任务时，后创建的任务可能无法暂停的问题；等待中的任务现在也可以正常暂停。
- 活动、暂停和异常中断任务统一显示在同一个任务列表中，每个任务始终只保留一张卡片。
- 暂停、继续、删除和进度统一在任务卡片内操作，批量操作也使用相同语义。
- 修复暂停任务被同时识别为中断任务、出现重复卡片，或从错误入口恢复后重复启动下载流程的问题。
- 删除暂停任务时会正确唤醒并终止后台下载，不再遗留等待中的任务。

## 影像与 Wayback

- 修复沿海和图源边界区域的无数据瓦片被计入下载失败，导致任务误标为“部分完成/缺块”的问题。
- Wayback 元数据扫描新增停止操作，离开页面时也会终止仍在运行的扫描和轮询。
- 修复 Esri 不支持 HTTP HEAD 时 Wayback 最大可用层级被低估的问题。

## 3D Tiles

- 3D Tiles 的 box 和 sphere 包围体现在会正确应用并继承 tile transform，改善选区空间过滤准确性。
- 外部 tileset 子树重试全部失败或内容文件下载失败时，任务会明确报告失败，不再显示为成功。
- 临时下载文件使用唯一名称，避免同名但不同扩展名的内容并发写入时发生碰撞。

## 安装与升级

- 本次升级不会自动删除已有任务、历史记录、输出文件或瓦片缓存。
- Windows、Linux、macOS Intel 和 Apple Silicon 安装包继续由 GitHub Actions 构建。
- macOS 安装包尚未进行 Apple Developer ID 签名与公证，部分系统仍可能显示安全提示。
