# GeoD 3.6.28 与采集服务发布（2026-11-06）

用户授权：检查线上失败是否需要修复，将已补诊断发布上线，桌面客户端发一版更新，采集服务一并更新。

确认并修复的代码问题：普通网络发送/读取失败缺少稳定分类，容易落入 UNKNOWN；直接瓦片目录创建/文件写入失败未统一为终止性存储错误，可能继续处理损坏数据。新增连接、超时、响应中断、请求发送及请求配置错误码；无效请求配置和本地写入失败及时停止并保留已有任务，尝试清除失败写入留下的部分文件。未将现有 404 覆盖/地址问题、429 限流或全部磁盘类上报宣称为已解决。

本版包含已提交的执行诊断：OSM 端点、状态码、耗时、备用切换与等待；天地图实际传输尝试、峰值、在途/等待、目标预算、用户配置与有效冷却。客户端和采集端闭合字段校验，兼容旧事件，不采集原始 URL、Key、查询、坐标或完整路径。

发布顺序：验证源码和协议 → 固定 v3.6.28 不可变源码/tag 并启动四平台构建 → 本地打包校验采集服务并固定主机密钥上传 → 数据库备份/隔离副本候选验证 → 原子切换采集服务、健康和新旧协议入库读回 → 五安装包本地/服务端/公网完整哈希校验 → 发布并原子激活镜像 → 官网桌面入口同步。

上线不修改数据库 schema，不操作用户安装器或鼠标，不更新 Agent 索引，不发送额外应用内通知。生产服务器不下载任何 GitHub 资源。采集服务、镜像、Nginx 和官网均保留回滚。未验证用户实际升级或读到通知。
