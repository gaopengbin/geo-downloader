# v3.6.10 - 坐标系导入、缓存容量与 AI 助手统计

本次版本重点修复 Shapefile 坐标系识别和瓦片缓存容量控制，同时完善多要素导入效率，并为开发者功能中的 AI 助手补充匿名使用统计。

## Shapefile 与坐标系

- 从桌面文件选择器导入单独的 `.shp` 时，会自动查找同目录、同名的 `.prj`、`.dbf`、`.shx` 和 `.cpg` 配套文件。
- 识别 `.prj` 后会将投影坐标转换为 WGS 84，再交给地图显示和下载范围计算。
- 缺少 `.prj` 时不再静默接受明显的米制投影坐标；界面会给出坐标示例和补齐配套文件的建议。
- 坐标位于正常经纬度范围但无法确认 CRS 时，会要求用户确认是否按 WGS 84 导入。
- 导入结果会显示识别到的坐标系和配套文件数量，便于排查 GIS 软件中的位置偏移。

## 多要素导入

- 导入多个面要素后可按名称筛选，并按原始顺序、名称或实际面积排序。
- `Shift` 连选会遵循当前筛选和排序后的可见顺序，不会误选被过滤掉的要素。
- 面积改为基于多边形球面面积计算，支持扣除内环，不再使用外接矩形面积冒充真实面积。
- 对无法可靠计算的坐标显示 `—`，避免出现负面积或误导性的数值。

## 瓦片缓存

- 下载持续写入缓存时会周期性检查容量上限，不必等到应用重启才触发清理。
- 清理过程会避开当前下载任务仍在使用的瓦片，并复用连接池减少大量小文件场景下的额外开销。
- 容量统计和自动清理状态保持同步，降低小容量磁盘被缓存占满的风险。

## AI 助手匿名统计

- 新增 AI 助手开启、面板操作、请求结果和 Agent 页面跳转等匿名事件。
- 请求耗时和知识来源数量只记录区间值，不记录精确内容。
- 不采集用户问题、模型回答、知识库原文、API Key、模型地址、文件路径或原始错误信息。
- 采集服务使用严格字段白名单，包含额外内容的事件会被拒绝。

## 安装与升级

- 本次升级不会删除已有任务、历史记录、输出文件、下载范围书签、设置或瓦片缓存。
- Windows、Linux、macOS Intel 和 Apple Silicon 安装包继续由 GitHub Actions 构建。
- macOS 安装包尚未进行 Apple Developer ID 签名与公证，部分系统仍可能显示安全提示。
