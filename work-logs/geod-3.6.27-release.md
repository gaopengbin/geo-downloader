# GeoD 3.6.27 在线更新修复（2026-11-03）

用户反馈在线更新再次变慢，沿用本会话已授权的在线更新修复和验证后发布范围。

根因：更新器继承 Windows 系统代理，国内安装包也绕行代理；同一请求库实测代理约 160–200KB/s，直连约 2MB/s。既有 64KiB/s 慢速阈值无法触发这种速度的回退，两条源也共用同一个代理客户端。

修改：国内直连 → 国内系统代理 → GitHub 系统代理。按线路选择独立客户端，保留重定向白名单、超时、大小/SHA-256/MZ 校验、失败清理和单更新锁，不改用户系统或图源代理设置。

发布前验证：

- 更新器 20 项回归通过，覆盖直接请求不触碰代理、国内直连失败后走同 URL 代理、两条国内线路失败后官方代理恢复，以及三线路均失败无残留/假完成。
- 桌面完整库 279 项通过、10 项显式网络/大体量测试按默认忽略；本次另单独运行真实生产下载器，保持本机系统代理开启，正式 3.6.26 安装包 10,606,568 字节完整下载并校验约 1.02 秒，第一条直连成功。未启动安装器。
- 速度随网络与缓存状态变化，该结果仅证明本机这次测试；不推断用户普遍速度或已安装。

本机已有 3.6.26 安装窗口保持不动。旧客户端二进制不能由服务器清单远程修改，新线路策略在升级到 3.6.27 后生效。发布保持不可变 tag、五包完整校验、固定主机密钥上传、服务端复核、原子激活和回滚流程；不更新 GeoD Agent 索引或发送额外应用内通知。
