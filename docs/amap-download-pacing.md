# 高德下载请求节奏

高德 `appmaptile` 下载使用进程内共享的请求预算：最多 4 个在途请求，
相邻请求启动间隔至少 62.5 毫秒（最多约 16 次/秒，不允许突发）。
遇到 429/503 后，共享预算遵守服务要求的等待时间并降低发送频率；
连续成功后才逐步恢复到上述初始节奏。天地图也采用独立的同类预算，
详见 [瓦片请求恢复](tile-request-recovery.md)。
多个任务、底图/注记和不同子域共用预算；重试与下载前核验也经过相同控制。
用户设置的较低并发仍然有效，缓存命中不占网络请求预算。地图在线浏览不经过此下载队列。

这些数值是客户端采取的保守策略，不是高德公布的配额，也不能保证消除所有 403。
持续的 IP、来源、权限或区域限制仍可能拒绝请求。HTTP 403 保持终止错误，
已有瓦片保留供用户修正配置后恢复；不会自动更换身份、代理或地址反复请求。

排查先区分底图和注记，再核对实际 HTTP 状态和网络路径。单次小样本成功不能证明
批量下载稳定；错误原因只根据已观察到的响应判断，不把本机成功当作用户反馈无效。
