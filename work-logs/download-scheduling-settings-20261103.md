# 开放下载调度参数（2026-11-03）

用户要求把可使用的下载调度参数开放到设置界面。本次在“设置 → 默认下载参数 → 下载调度”增加三项：

| 参数 | 默认与含义 |
| --- | --- |
| 每秒请求上限 | 0：自动，不额外限速；正整数：额外上限，范围 0–10000 |
| 每批请求数 | 0：不分批；正整数：每批请求尝试数，范围 0–100000 |
| 批次停顿（毫秒） | 0：随机 600–2200ms；正整数：固定停顿，范围 0–600000 |

旧设置缺少新字段时全部默认 0，维持原有自适应策略。相同服务/Token 的任务共享调度；常规其他 HTTP(S) 图源按 origin 共享。影像、叠加层与重试均在实际下载请求入口计数，文件复用不进入请求预算。整批所有在途请求结束后才开始停顿，排队取消不占用后续名额。

用户限制和服务侧限流在同一个准入点组合，避免两个独立等待器累积后同时发出请求。新配置持久化后通知等待者，作用于后续请求；保留原有 provider 和本地 Retry-After 冷却。等待批次停顿时下载卡片显示对应的中英文消息。地图浏览、Google Earth 专有历史传输、OSM 查询与 3D 下载保持独立调度，界面明确说明适用范围。

保存时有前后端范围校验及回读核验；读回不一致显示错误，不报保存成功。禁用 AI 字段不阻断本次保存；非法数值显示本地化错误，禁用浏览器原生表单校验气泡。未改动用户真实配置或图源凭据。
