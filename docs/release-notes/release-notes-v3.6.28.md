# GeoDownloader v3.6.28

本次更新完善下载失败处理与诊断，帮助分清图源限流、网络错误、调度等待和本地存储失败。

## 下载失败处理

- 连接失败、请求超时、响应传输中断、请求配置错误使用明确的错误码和提示，减少笼统的“未知错误”；诊断不上传原始地址、密钥或错误文本。
- 无效请求配置和本地瓦片写入失败及时停止，保留已有任务数据；写入失败留下的不完整瓦片会尝试清理，避免恢复时误认为已完成。
- 图源返回 404 或 429 时继续保留原有无数据判断、冷却与恢复规则。

## OSM 和天地图执行诊断

- OSM 记录每个备用服务的尝试、HTTP 状态、耗时、错误类型、排队及冷却等待；区分 HTTP 200 后的传输中断和不完整结果。
- 天地图按任务统计实际传输尝试、滚动一秒峰值、并发、限流响应、目标速率、用户配置及实际等待；混合图层的其他图源不混入天地图速率。
- 排队中的请求和取消等待也保留已观察信息，帮助分清正常限速与等待异常。
- 客户端、采集端和本地诊断文件共用受限字段；不采集图源完整 URL、请求头、Key、OSM 查询、坐标或保存路径。

网络条件、图源覆盖、访问限制和本地空间仍可能导致任务失败。新诊断用于升级后的任务，不能补回历史记录中未采集的信息。
