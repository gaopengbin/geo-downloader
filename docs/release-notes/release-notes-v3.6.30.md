# GeoDownloader v3.6.30

## 下载与导出

- 卫星影像导出 GeoTIFF 时可以选择「JPEG 75」有损压缩。保留地理坐标、裁剪掩膜和金字塔，适合希望减小成品体积的影像任务。
- 优化大范围影像的 JPEG 编码、共享缓存写盘和磁盘空间估算。批量任务在拼图和导出阶段也遵守并发限制。
- 下载中心支持重试失败任务。修复老任务断点可能被清理、成品已写出但重启后缺少成功记录的问题。瓦片和 3D 下载失败时保留具体原因。
- 多级输出的历史卡显示实际导出的级别，支持连续和不连续的选择。

## 地图与更新

- 修复多区域选择在部分预览、批量提交和导出路径中遗漏区域的问题。
- 改进在线更新源切换。镜像返回不完整的安装包信息时，会继续检查备用源。仍有任务在写盘时，客户端会推迟安装更新。
- 启用匿名统计时，任务恢复成功后会更新最终结果。重启补记已生成的文件会沿用原任务，避免重复计算下载次数。
