# GeoD 官网、账号与产品站点规划（2026-09-25）

## 当前核对结果

| 入口 | 现状 | 应承担的职责 |
| --- | --- | --- |
| `laogao.xyz` | 作者与多产品总入口 | 介绍不同产品并把用户送到各自官网；不承载 GeoD 的登录态 |
| `geod.laogao.xyz/` | GeoD 桌面端官网，已有 CLI、MCP、浏览器版页面 | GeoD 产品总入口、文档、下载、账号入口 |
| `geod.laogao.xyz/browser` | 浏览器影像下载和 WebMCP，原登录链接误指向 `/geod` | 本机影像工具；高级别下载经 GeoD 账号验证 |
| `geod.laogao.xyz/geod` | 独立的地图创作工作台页面；不是登录页 | 地图创作产品的介绍和工作区 |
| `geod.laogao.xyz/api/account/*` | 当前 GeoD 账号 API，已支持邮箱登录、验证码注册/重置、会话和创作额度 | GeoD 身份的现有服务入口；产品用量须分账显示 |
| `geostyle.laogao.xyz` | 另一产品站点 | 保留独立品牌与入口；不作为 GeoD 官方登录页 |
| `geodownloader.pages.dev` | 旧的 GeoD 站点仍可访问 | 后续标明迁移入口，避免成为并行维护的第二套官网 |

微信聊天生成器、CodeDrobe 等其他产品不属于 GeoD 账号体系。本规划不迁移它们的用户信息，也不让 GeoD 账号页列出它们的余额或作品。GeoD Global 有独立仓库与发布边界，不直接并入国内站点。

## 推荐信息架构

```text
laogao.xyz                 作者与产品目录
└─ geod.laogao.xyz         GeoD 官网与产品总入口
   ├─ /                    产品概览与桌面端下载
   ├─ /browser             浏览器影像下载 / WebMCP
   ├─ /cli                 本地 CLI
   ├─ /mcp                 本地和远程 MCP / Skill
   ├─ /geod                地图创作工作台（现有应用）
   ├─ /login               官方登录、注册、找回密码
   └─ /dashboard           我的 GeoD：身份、安全、产品入口、已接入的产品用量
```

主导航只保留用户要去的产品和账号入口；历史版本、文档、法律说明放页脚。所有“需要登录”操作带站内 `returnTo`，登录后回原任务；直接访问 `/login` 默认进入 `/dashboard`。不接收站外跳转地址。

## 账号与权限边界

1. GeoD 账号提供稳定用户 ID、邮箱验证与会话。CLI、本地 MCP、远程 MCP 和浏览器都识别同一身份；它们各自保存任务或在用户设备运行，不把本机下载历史伪装成云端历史。
2. 浏览器与官网共享 `geod.laogao.xyz` 的同站会话。当前 `/api/account` 是现成的账号合同；新页面复用它，不建立第二张用户表。
3. `laogao.xyz/geod-mcp` 的 OAuth 目前是另一主机上的授权流程。长期应由 GeoD 官方登录页发起一次性授权交接，服务端交换短时 code 并验证回调；不能简单共享/复制浏览器 Cookie 或把令牌写进 Agent 对话。
4. 账号身份与产品权益分开：影像下载级别、MCP 服务资源、地图创作积分和未来充值余额分别记账。控制台只有在对应产品提供真实查询接口时才展示用量；现有 `quota` 明确标注为“地图创作额度”。
5. 当前 CLI/浏览器的本机限制是产品侧规则，不能单独充当收费防篡改边界。正式计费前需要服务端签发可校验的权益，并明确离线使用策略。

## 实施顺序与验收

### 本次：入口与可用的账号工作流

- 发布 `/login`：邮箱密码登录、邮箱验证码注册/重置、中文错误提示、返回原页面。
- 发布 `/dashboard`：真实会话身份、地图创作额度的正确归属、产品入口、退出和密码修改。
- 修正浏览器影像页的登录入口；官网导航区分浏览器、CLI、MCP 和地图创作。
- 验收匿名页面、错误状态、登录跳转、静态站构建、桌面/窄屏布局；实际注册、密码修改和已登录高级别下载需要账号持有人完成敏感操作验收。

### 下一阶段：独立 GeoD 身份服务

- 把当前 `/api/account/*` 从地图创作运行服务中抽出为独立 GeoD 身份服务；保留用户 ID 与可审计的数据迁移，先双读校验再切流量。服务和数据需备份并有回滚方案。
- 统一 CLI/MCP OAuth 授权外观与官方登录页，支持安全的跨主机授权交接。
- 控制台增加每个产品的真实任务、额度、账单和应用授权管理。没有 API 的产品只给入口，不显示虚构统计。

### 站点收敛

- 在旧 `geodownloader.pages.dev` 增加明确的新官网入口和 canonical/迁移说明；核对搜索结果后再考虑重定向。
- `laogao.xyz` 只保留 GeoD 产品卡片与深链接，不复制一套 GeoD 登录/控制台。
- 其他产品站点先各自独立；是否加入同一账号体系以数据、权益和运营需求单独决策。
