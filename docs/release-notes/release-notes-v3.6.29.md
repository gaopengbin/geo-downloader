# GeoDownloader v3.6.29

## 矢量数据

- 原 OSM 模块改为「矢量」，集中提供 OSM 要素、行政区边界、本地矢量和国家基础地理参考要素的入口。
- OSM 要素可按视口或所选区域加载到地图，支持多边形预览。预览由原生端生成图像瓦片，可在地图图层面板开关或移除。
- 水系、公路、铁路、居民点与地名可在地图上单独叠加，支持调整样式和坐标对齐。当前视口可另存为 GeoJSON。

## 图源

- CARTO Light 和 Dark 更新 Key 后直接读取对应的网络瓦片，避免继续显示旧的「API KEY REQUIRED」水印。
- 自定义图源支持转换奥维在线地图模板，包括服务器路径、瓦片坐标和子域名变量。转换后可用普通自定义图源流程预览和管理。

## 下载结果统计

- 开启匿名统计时，同一下载任务的重试可关联到最新结果。统计管理页可查看完整完成、恢复成功、最近一次失败、缺块完成、取消和待上报的数量。
- 旧客户端上报的记录继续按下载尝试统计。任务关联使用随机标识。
