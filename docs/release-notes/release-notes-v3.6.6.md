# v3.6.6 - 大任务稳定性、GeoD 助手与地图交互

本次稳定版整合了 3.6.6 两个测试版本的验证结果，重点改善大规模下载任务的恢复速度、磁盘空间保护和地图操作体验，并加入默认关闭的 GeoD 助手开发者功能。

## 大任务与磁盘保护

- 大型任务的中间瓦片改为按列分目录保存，避免单目录包含海量文件导致扫描和重启恢复变慢。
- 新任务的工作目录保存在输出目录旁的 `.geod-work` 中，减少大型任务持续占用系统盘的风险。
- 创建任务和下载过程中都会检查剩余磁盘空间；空间不足时停止写入并保留恢复数据。
- 旧版本保存的未完成任务仍可识别，旧的平铺式中间文件也可以继续恢复。

## 地图与界面

- 图层管理面板改为点击展开、点击外部关闭，修复鼠标移入面板时意外收回的问题。
- 调整 Wayback 图层面板位置，避免与时间轴相互遮挡。
- 经纬网支持自动细化或固定间隔，用户可以按底图和当前缩放级别选择显示方式。
- 经纬度、缩放级别和三维视角高度统一移到地图外的底部状态栏，减少地图内控件遮挡。
- 修复助手与图源管理同时打开时的布局错位，以及主题菜单点击无响应的问题。

## GeoD 助手与图源配置

- GeoD 助手作为开发者功能默认关闭，可由用户自行配置 DeepSeek Key 和 AI 网关。
- 助手使用 GeoD 知识库回答常见问题，并可通过回答中的操作链接跳转到相关设置位置。
- 图源管理新增智能解析，可从用户提供的 URL 辅助识别瓦片模板、测试可用性并引导完成配置。
- 启用助手前会展示风险提示、免责声明和隐私说明，并要求用户再次确认。

## 匿名使用统计

- 匿名统计必须经过用户明确同意后才会启用，可随时在设置中关闭或重置匿名标识。
- 仅统计应用版本、系统平台和少量功能开关事件。
- 不采集图源 URL、文件路径、文件名、搜索内容、坐标、选区范围、Token、API Key 或下载数据。
- 统计服务由 GeoD 自托管，关闭后会立即清除本地待发送队列。

## 安装与升级

- Windows、Linux、macOS Intel 和 Apple Silicon 安装包均由 GitHub Actions 构建。
- macOS 安装包执行 ad-hoc 签名和打包后校验，但尚未进行 Apple Developer ID 签名与公证，部分系统仍可能显示安全提示。
- 稳定版用户可通过应用内更新检查升级；升级不会自动删除已有任务、历史记录或瓦片缓存。
